# 프로티원 행사 운영 웹서버

시트_260831의 구조를 기준으로 행사 계획, 대행사 전달 내용, 상품별 정산, 미디어 집행, 성과 이력 및 원본 보관함을 제공합니다.

## 데이터

- 기준 통합문서 11개 시트: RAW, MASTER, 상품·원가·옵션·채널·행사·템플릿·광고·성과 DB, 시트_260831.
- 행사시트.zip의 26개 Excel 파일, 728개 시트를 추출했습니다.
- 성과 311개 원본 기록, 미디어 계획 121개 기록, 상품 27개, 원가 30개를 보존했습니다.
- data/*.json은 원본의 저장된 계산값입니다. 매크로·문서 내부 지시를 실행하지 않습니다.
- 다운로드 가능한 원본에는 수식, 이미지, 주석 및 서식도 그대로 보존됩니다.
- source_sheets는 최초 열람한 원본 스냅샷을 D1에 저장합니다. 미열람 원본은 함께 배포된 원본 스냅샷에서 조회할 수 있습니다.
- event_plans는 로그인 사용자별 행사 운영 내용을 저장합니다. 버전 검사를 통해 동시 수정 덮어쓰기를 차단합니다.

## 실행

Node.js 22.13 이상 및 npm이 필요합니다.

```text
npm run install:ci
npm run db:generate
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_zippy_paibok.sql
npm run dev
```

기존 DB에서는 같은 마이그레이션을 반복 적용하지 마세요. 로컬 주소는 http://localhost:5173 입니다. 로컬 로그인은 스타터의 테스트 사용자이며, 배포 사이트는 Sites 인증과 비공개 접근 정책을 사용합니다.

## 계산 및 제한

세팅가 = 최종 소비자 결제가 / (1 - 할인율). 자사 매출 = 세팅가 - 자사 부담 할인. 수수료는 선택한 세팅가·자사 매출·소비자 결제가 기준에 곱합니다. 정산액에서 구성 원가, 판매단위당 배송·물류·포장비, 광고비와 기타비용을 차감해 공헌이익을 계산합니다. 공헌이익률의 분모는 자사 매출입니다.

원본의 오류 및 빈 수량은 미확정으로 유지합니다. 누락값을 0으로 바꾸어 이익을 확정하지 않습니다. 실제 판매가 없으면 수량에 0을 입력하세요. 단품 원가와 세트 원가는 구분해 입력해야 합니다. 가격 가이드의 0은 미확정을 의미합니다.

바·파우치의 원본 수수료 기준이 #REF!이므로 템플릿에서 소비자 결제가를 임시 적용하고 메모에 표시했습니다. 신규 행사에도 조건과 원가 검토가 필요합니다. 원본 내 채널 불일치, 누락 원가, 복사본·시뮬레이션은 자동 정정하지 않습니다. 과거 성과의 ROAS와 공헌이익은 원본 단위를 그대로 표시하며 중복 매출을 합산하지 않습니다.

기준 데이터와 과거 이력은 원본 스냅샷이며 Excel과 실시간 양방향 연동하지 않습니다. 운영 행사의 저장값과 새 계산은 별개입니다.

## 검증

- node scripts/check-calculations.mjs: 세 가지 수수료 기준, 원본 정산값 대조, 손익, 누락/0, 입력 검증.
- node scripts/check-api.mjs: 실행 중인 로컬 서버에서 원본 대조, 저장/조회/수정, 버전 충돌, 잘못된 입력 및 외부 Origin 차단. 로컬 테스트 레코드 정리 SQL을 .sites-runtime/qa-cleanup.sql에 만듭니다.
- TypeScript 검사 및 배포 빌드.
- 원본 보관함과 좁은 화면 레이아웃을 브라우저에서 확인했습니다.
- WebMCP 도구 등록은 확인했지만 브라우저 연결 중단으로 실행 검증은 완료하지 못했습니다. 일반 화면 조작과 API에는 영향이 없습니다.
